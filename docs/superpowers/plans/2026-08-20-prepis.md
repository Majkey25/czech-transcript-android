# Přepis implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Vytvořit jednoduchou offline Android aplikaci pro české přepisy M4A nahrávek z jedné vybrané složky.

**Architecture:** Jedna Compose activity drží tři obrazovky bez navigační knihovny. SAF poskytne seznam souborů, WorkManager je sériově zpracuje a privátní textové soubory nahradí databázi.

**Tech Stack:** Kotlin 2.3.21, AGP 8.13.2, Compose BOM 2026.06.01, WorkManager 2.11.2, sherpa-onnx 1.13.4, Android MediaCodec.

**Spec:** `docs/superpowers/specs/2026-08-20-prepis-design.md`

## Global constraints

- `minSdk = 26`, `targetSdk = compileSdk = 36`, JVM 17, pouze `arm64-v8a`.
- Žádný cloud, analytika, databáze, přehrávač ani rozlišení mluvčích.
- České texty jsou UTF-8 s diakritikou. Nahrávky se pouze čtou.
- Modelové soubory jsou připnuté na revizi `8f3c18b358db4d1f2fc1eae49d75cd20989e4309` a po stažení se ověří SHA-256.
- All application UI strings are English. ASR remains fixed to Czech (`cs`).
- Physical-device QA is forbidden. Use the existing emulator only.
